# Elite Conceal™ Website - Features Overview

## 🎨 Visual Design

### Color Palette
- **Primary Dark**: `#171717` (Neutral 900) - Deep charcoal
- **Secondary Dark**: `#0a0a0a` - Midnight black
- **Accent Gold**: `#f59e0b` (Amber 500) - Brushed gold
- **Light Accent**: `#fbbf24` (Amber 400) - Champagne gold
- **Background**: `#f5f5f5` (Neutral 50) - Warm white
- **Text**: High contrast combinations for readability

### Typography
- **Display Font**: Playfair Display (Serif) - For headlines and emphasis
- **Body Font**: Inter (Sans-serif) - For body text and UI elements
- **Font Sizes**: Responsive scaling from mobile to desktop
